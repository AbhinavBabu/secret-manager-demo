Security Details
Secrets Retrieval

Bucket name, KMS key ARN, SMTP credentials, and admin email are all retrieved dynamically from AWS Secrets Manager at runtime. No credentials exist in source code.

At-rest Encryption

Every uploaded object is encrypted with your Customer-Managed KMS Key (CMK) via SSEKMSKeyId before being written to S3.

Secure Downloads

Files are never publicly accessible. Downloads use pre-signed S3 URLs with a 15-minute expiry generated on-demand by the backend.

IAM Instance Role

The EC2 instance uses an IAM Instance Role with scoped permissions. No AWS Access Keys are stored on the instance or in code.
